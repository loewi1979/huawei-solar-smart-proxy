# Huawei Solar Smart Proxy 1.0.1

Documentation update to release 1.0. No application behavior or configuration
defaults have changed.

- Added and clarified English comments in all 20 new or modified Go source and
  test files, including polling, caching, freshness, MQTT, Modbus forwarding,
  authentication, YAML configuration and the web dashboard.
- Corrected outdated descriptions of startup, retries and scheduling to match
  the existing implementation.
- A token-by-token comparison confirmed unchanged executable Go code, including
  literals and implicit semicolons. The full test suite and vet passed.
- Published fresh Linux amd64/arm64 packages and multi-platform container images
  for this documented source revision. Docker examples now pin version 1.0.1.

Existing configurations remain valid. Updating the running proxy is optional
for this comments-only application change; this release does not modify HA,
Victron or inverter settings.
